
# JMA Finance for iPhone

Native SwiftUI iPhone version of the JMA Finance app.

Included:
- 4-digit PIN lock
- Income and expense entry
- Current balance
- Day / Week / Month summaries
- History with swipe-to-delete
- Reports chart
- Settings and PIN change
- Euro (€)
- Local on-device storage
- Dark/neon JMA-style interface

## Open in Xcode
1. Extract the ZIP on a Mac.
2. Open `JMAFinance.xcodeproj`.
3. Select your iPhone or an iPhone Simulator.
4. In Signing & Capabilities, choose your Apple Development Team.
5. Press Run.

Target: iOS 17 or later.

To install permanently on an iPhone or publish to the App Store, Apple code signing is required.
